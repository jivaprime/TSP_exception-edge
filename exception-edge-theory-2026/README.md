This folder is the curated public release of the 2026 exception-edge study for
Euclidean TSP. It separates three evidence levels:

1. **proved statements** about baseline-relative exception edges, cut
   interfaces, closure spectra, and the \(\kappa=1\) identity;
2. **exact-small computation and safe certificates**;
3. **exploratory LIN318 scale-up** using verified LKH closure witnesses and
   deterministic candidate-restricted 2/3-opt.

## Central idea

Fix a sparse baseline graph \(G_0=(V,E_0)\), usually the weak-Delaunay graph.
An edge is exceptional only **relative to \(G_0\)**. For a nonbaseline edge
\(e=\{s,t\}\), let \(H_e\) be the cheapest spanning Hamiltonian
\(s\)-to-\(t\) path using only \(E_0\), and let \(Z_0\) be the cheapest
baseline-only cycle. Then

\[
C_e=H_e+c(e),\qquad
G_e=Z_0-C_e,\qquad
\kappa_e=\frac{Z_0-H_e}{c(e)}.
\]

The exact first-order threshold is

\[
\kappa_e>1
\iff G_e>0
\iff H_e+c(e)<Z_0.
\]

This says that one closure edge beats the baseline-only optimum. It does
**not** say that the edge is in a global optimum, is forced, or dominates
solutions using two or more exception edges.

## Headline evidence

| Evidence layer | Result | Correct interpretation |
|---|---:|---|
| Stage 2 exact-small | 177 of 178 raw mandatory cases had \(q=1\) | Strong observed concentration, not a universal theorem |
| Stage 3 natural core | 51/51 mandatory cases were exact global/exclusive \(q=1\) | Exact within the frozen \(n\le12\) corpus |
| Stage 3 certification | 48/51 natural-core mandatory cases safely certified | Coverage of the present inequalities |
| Stage 3 candidate bound | 15,054 pairs reduced to 644, preserving 600 exact supports | Exact-small support-preserving audit |
| LIN318 safe scan | 13 of 512 added candidates had a positive safe lower bound | Sufficient positives; the other 499 are inconclusive |
| LIN318 basin exploration | 42,210 → 42,118 → 42,108 | LKH-seeded exploratory intervention, not an independent solver |
| LIN318 post-hoc gap | 79 above 42,029 (0.18797%) | The optimum was not reached |

The LIN318 1,500-edge search graph was **not generated by the threshold
theory**. It consists of 988 weak-Delaunay edges plus a separately constructed
512-edge candidate set. The threshold experiment screens those 512 edges.

## Quick audit

Python 3.12+ is recommended.

```bash
python -m pip install -r requirements.txt
python verify_public_results.py
python -m unittest discover -s tests -v
```

The deterministic end-to-end basin reproduction is:

```bash
python verify_public_results.py --full
```

No optimum tour is read by either audit. The compact bundle contains only the
sealed candidate snapshots and saved 2-factor needed for reproduction.

## What is included

- `docs/`: integrated theory, proof sketches, experimental protocol, results,
  claim ledger, provenance, and reproduction guide.
- `exception_edge/`: exact closure, safe-bound, MILP, closure-witness, and
  candidate-restricted local-search code used by the published checks.
- `tests/`: synthetic theorem/oracle checks, witness verification tests,
  MILP tests, and the LIN318 reproduction test.
- `results/exact_small/`: selected summary tables and figures.
- `results/lin318/`: the full 512-row scan table, 45 witnesses needed by the
  reproduction, restricted-baseline evidence, sanitized basin tables, and
  published tours.

Large intermediate files, repeated quick runs, LKH work directories, the LKH
binary, and the TSPLIB source instance are deliberately excluded.

The exact-small code in this compact release covers the core oracle,
safe-bound implementation, fixtures, and frozen-summary audit. The study
drivers, generators, configs, and large pair tables used to generate the full
541/600-instance Stage 2/3 corpora are not included, so this is not a
from-scratch corpus regeneration package. Earlier Stage 1 CUT and Stage 1B
density-CUT negative results are summarized in the results document, while
their raw artifacts and drivers remain outside this compact release.

## Non-claims

This release does not claim a polynomial-time TSP algorithm, resolution of
NP-hardness, complete classification of all exception edges, superiority over
LKH, an LKH-free LIN318 solver, or a controlled causal effect for one edge.
See the [claim ledger](docs/CLAIM_LEDGER_KO.md).
