## TSPLIB

The LIN318 benchmark is identified by name, dimension, objective convention,
and source-file SHA-256. The original TSPLIB problem file is not distributed
in this folder. Users should obtain benchmark instances from an authorized
TSPLIB mirror and follow its terms and attribution requirements.

Primary bibliographic reference:

> Gerhard Reinelt. “TSPLIB—A Traveling Salesman Problem Library.” ORSA Journal
> on Computing, 1991.

## LKH

LKH was used as a heuristic generator of feasible forced-closure tours in the
LIN318 scale-up. Its executable is not included. The experiment pinned the
executable byte hash
`ebcf9f2461212b0fbe5f21feead9d6c2870f03c02b6bbb34a3cb4e6675ebdc85`.
Users must obtain LKH separately and comply with the upstream academic and
non-commercial terms.

Primary bibliographic reference:

> Keld Helsgaun. “An Effective Implementation of the Lin–Kernighan Traveling
> Salesman Heuristic.” European Journal of Operational Research, 2000.

## NumPy and SciPy

The public verification code uses NumPy and SciPy under their respective open
source licenses. SciPy provides spatial Delaunay/Qhull interfaces and the
HiGHS-backed mixed-integer optimizer used by the restricted-cycle audit code.
No third-party binary is vendored in this folder.
